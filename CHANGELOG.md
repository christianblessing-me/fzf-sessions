# Changelog

## 0.1.0

Initial release — 13 November 2026.

- Find and resume local Codex and Claude Code sessions across repositories.
- Separate folder/title fuzzy search and literal conversation search.
- Optional on-device Apple Intelligence recaps, matching excerpts, and recorded token usage.
- Herdr popup with open-session detection, refresh, and navigation across workspaces.
- Shortcut modal, quoted resume-command copying on macOS, and color controls.
- Defensive transcript parsing, indexed search, bounded summary caches, and cached preview usage.
- User-local installation, dependency diagnostics, and macOS/Linux CI with required terminal checks.
